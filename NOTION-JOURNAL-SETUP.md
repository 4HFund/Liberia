## One-time Notion setup

1. In the Notion iPhone app or notion.com, create a page named **Liberia • The Journey**.
2. Paste the optional starter copy below. Add new daily updates at the TOP so newest posts show first.
3. In Notion, use **Share → Publish → Publish**. Copy the published public URL (not the private workspace URL). Verify it opens without signing in.
4. In Notion's published-page controls, choose **Embed this page → Copy code**. From that code, copy the URL inside iframe's **src="..."** (the embed URL). "Show page title" can be off for a cleaner appearance.
5. In /assets/journey-updates.js, replace the two empty strings:
   const notionPublicUrl = "https://your-public-notion-page";
   const notionEmbedUrl = "https://your-notion-embed-src";
   Commit the change to main. Visitors will see the embedded Notion journal and a link to open the full page.
   
Alternatively, send both links or the copied embed code to ChatGPT, and ask it to connect the page in this GitHub repository.

**After setup:** Every edit saved in Notion appears on the public page without editing GitHub. The Notion embed inside the website will show the latest content upon refresh. Internet access is required for the public Notion embed.

**Important:** Publishing a Notion page can also publish child pages. Do not place private contacts, personal travel details, passport data, sensitive photos, or identifying information about others (especially children) in the public journal. Obtain appropriate permission before sharing people's stories or photos. Notion may display contributor profile information in a published page's metadata. Invite Pastor Bobby as a Notion editor privately; don't turn on public editing.

## Simple mobile posting routine

- Open Notion on iPhone and edit **Liberia • The Journey**.
- Add a heading with a date and place; 2–4 sentences; add 1–3 photos, a video link if available, and a short "How to pray" line.
- Put the newest update at the top.
- Close Notion. Visitors can check https://100acresofhope.com/#updates (refresh to see changes).
